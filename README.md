# PROVOSTCGMN_labecassiere

Site vitrine de **La Bécassière** — maison de famille normande avec piscine chauffée privée, à 10 minutes de Honfleur (Genneville, Calvados).

Site one-page en 4 langues : français, anglais, allemand, suédois.

## Structure

- `index.html` — le site complet (HTML + CSS + JS, sans dépendance externe sauf Google Fonts).
- `images/` — les photos du bien.

## Mise en ligne (GitHub Pages)

1. Pousser le dépôt sur GitHub.
2. Dans le dépôt : **Settings → Pages → Build and deployment → Source : Deploy from a branch**, branche `main`, dossier `/ (root)`, puis **Save**.
3. Le site est publié sous quelques minutes à l'adresse :
   `https://gprovost67-apetit.github.io/PROVOSTCGMN_labecassiere/`

## Nom de domaine personnalisé (optionnel)

Pour utiliser `labecassiere.fr` : ajouter un fichier `CNAME` contenant `labecassiere.fr`,
puis configurer les enregistrements DNS chez le registrar (4 enregistrements A vers les IP GitHub Pages).

## Remplacer une photo

Déposer la nouvelle image dans `images/` sous le même nom de fichier, puis pousser.
Aucune modification du code n'est nécessaire.
